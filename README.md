# 基于 UE4-AirSim 的单卡车多无人机协同配送仿真系统

> 版本 **V1.0** · Unreal Engine 4 · Microsoft AirSim · Python 3.8 · Windows

基于 UE4 与 AirSim 构建的车机协同配送仿真平台：以单辆运输卡车作为移动补给站，搭载多架无人机完成配送任务，覆盖卡车路径规划、多机任务分配、自主起降、货物投递、协同补给与实时三维可视化全过程，为智慧物流调度策略验证提供高保真数字孪生环境。

## 开发背景

随着低空经济和智慧物流的发展，无人机配送与地面车辆协同运输已成为智能物流的重要研究方向。传统单一配送方式存在配送效率低、覆盖范围有限等问题，因此提出**车机协同配送**模式：以运输车辆作为移动补给平台，提高无人机续航利用率与配送效率。

本软件基于 Unreal Engine 4 和 Microsoft AirSim 开发，构建真实物流配送场景下的数字孪生环境，实现单辆卡车搭载多架无人机协同执行配送任务的全过程仿真。

**可用于：**

- 多无人机协同配送策略验证
- 车机联动补给机制研究
- 智慧物流调度算法测试
- 无人系统路径规划与任务分配实验
- 多智能体协同控制教学与科研仿真

## 功能特性

| 模块 | 能力 |
| --- | --- |
| **卡车调度** | 按配送节点顺序移动、动态更新位置、与无人机协同停靠、到站触发补给 |
| **多无人机初始化** | 三架及以上无人机同时初始化、自定义出生点、独立飞行高度、多窗口视角 |
| **无人机飞行控制** | 基于 AirSim API 的起飞 / 降落、路径跟踪、自动返航、悬停控制 |
| **多机任务分配** | 自动任务分配、节点优先级调度、动态重规划 |
| **电耗载荷管理** | 剩余电量可支撑里程与载荷显示、投递点动态减载、补给点自动补满 |
| **安全避障** | 碰撞检测、安全悬停、异常状态报警 |
| **任务调度同步** | 多线程并发控制、事件同步机制、无人机 / 卡车状态协调、补给完成判定 |
| **可视化跟踪** | 实时展示无人机位置、配送路径、节点连接关系、当前任务状态 |

## 系统架构

系统采用分层模块化设计：

| 层级 | 职责 | 实现 |
| --- | --- | --- |
| **数字场景建模层** | 配送地图与障碍环境 | UE4 场景与资产 |
| **仿真控制层** | 无人机 / 车辆物理仿真接口 | AirSim 插件 |
| **调度决策层** | 任务分配与路径规划算法 | Python 客户端（经 AirSim RPC 调用） |
| **可视化监控层** | 实时显示配送状态、节点关系、电耗载荷变化 | UE4 HUD / 拓扑图 |

## 技术特点与创新点

- **多智能体协同控制**：多无人机并行执行配送任务，独立路径飞行、同步任务调度、协同补给
- **车机协同补给机制**：地面车辆作为动态补给站，无人机中途降落补货后继续配送
- **动态载荷管理**：按任务点投递需求自动扣减载荷与电耗，补给点自动恢复满载满电量
- **三维可视化仿真**：基于 UE4 高保真场景的三维地图、实时飞行姿态与多视角监控

创新点：

1. 提出单卡车多无人机协同配送仿真
2. 实现配送任务动态调度与路径规划
3. 支持多无人机异步配送协同机制
4. 集成 AirSim 与 UE4 实现高保真仿真验证
5. 支持多视角实时监控与状态可视化
6. 实现配送载荷动态管理

## 快速开始

1. **准备引擎**：安装 Unreal Engine 4.27，并将本项目与引擎关联（右键 `csy.uproject` → *Switch Unreal Engine version*）。
2. **获取工程资产**：`Content/` 目录未纳入版本库（见[注意事项](#注意事项)），需向维护者索取后放回工程根目录，否则地图与蓝图无法加载。
3. **生成解决方案**：右键 `csy.uproject` → *Generate Visual Studio project files*。
4. **编译**：用 Visual Studio 2022 打开生成的 `csy.sln`，编译 `Development Editor | Win64`。
5. **启动仿真**：运行 `csy.uproject` 打开编辑器并播放场景，AirSim 插件会随场景启动并监听 RPC 端口。
6. **接入调度程序**：运行 Python 3.8 客户端（需安装 `airsim`、`msgpack-rpc-python` 等依赖），连接 AirSim 后按[操作流程](#操作流程)执行配送任务。

> 首次编译 AirSim 插件若无预编译库或需修改 AirLib 源码，请参考 [microsoft/AirSim](https://github.com/microsoft/AirSim) 的 Windows 构建说明重新生成 `AirLib`。

## 操作流程

| 步骤 | 操作 |
| --- | --- |
| **1. 启动仿真环境** | 运行 UE4 场景，加载 AirSim 插件 |
| **2. 初始化车辆与无人机** | 卡车生成、多无人机挂载、参数初始化 |
| **3. 无人机起飞校准** | 无人机飞至卡车顶部装载点完成初始校准 |
| **4. 执行配送任务** | 按预设路径依次飞往各配送节点完成投递 |
| **5. 实时监控运行状态** | 显示当前配送路径、剩余载重与电耗、碰撞信息 |
| **6. 中途补给** | 无人机飞至补给点 P3 → 降落至卡车顶部 → 自动补充载荷 → 再次起飞执行后续任务 |
| **7. 任务完成返航** | 所有配送完成后返回起始点降落 |

## 界面说明

**系统主界面**由四部分组成：

- 左侧：系统日志输出区
- 中间：主视角仿真画面
- 右上：配送拓扑图
- 下方：各无人机状态窗口

其余界面包括：多机起飞界面、到达点位减载界面、离开点位界面、无人机降落补货界面、任务完成界面（截图见《设计说明书》V1.0）。

系统运行后可实现：三架无人机按预定路径协同配送、卡车自动行驶至补给点、无人机自动降落补货、实时显示配送状态与载荷变化、完成任务后返航降落。

## 注意事项

- **`Content/` 未入库**：工程资产（`.uasset` / `.umap`，约 8.6 GB）超过 GitHub 单文件 100 MB 上限与 Git LFS 免费配额，因此未提交。被排除的资产包清单见 [`Content/README.md`](Content/README.md)，拿到后放回工程根目录即可。
- **插件预编译库**：`Plugins/AirSim/Source/AirLib/lib/` 下保留了两个预编译 `AirLib.lib`（Debug / Release，分别约 89 MB、86 MB），以便克隆后直接编译；若改为源码构建 AirLib，可将该目录移出版本库。
